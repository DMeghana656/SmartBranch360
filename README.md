# SmartBranch360

## Project Overview
SmartBranch360 is a secure branch office network designed using Cisco Packet Tracer.

## Features
- VLAN Segmentation
  - VLAN 10 - ADMIN
  - VLAN 20 - EMPLOYEES
  - VLAN 30 - SERVER
  - VLAN 40 - GUEST
  - VLAN 99 - MANAGEMENT

- Inter-VLAN Routing
- DHCP Configuration
- Access Control Lists (ACLs)
- Secure Network Design
- Guest Network Isolation
- Server Connectivity
- Multi-Switch Topology

## Tools Used
- Cisco Packet Tracer
- Python
- Flask
- MySQL

## Network Topology
- 1 Router
- 2 Switches
- Admin PCs
- Employee PCs
- Server
- Guest Network
